# MonCheptel
**Gestion d'élevage · Projet réalisé en binôme**

## Besoin
Regrouper le suivi du cheptel et les informations utiles à la gestion d'une exploitation dans une application web et mobile.

## Solution
Le projet comprend une application Flutter pour les espaces éleveur et vétérinaire, une administration web Angular et une API Spring Boot avec MySQL.

## Ma contribution
La répartition documentée dans le projet attribue à Balla Sow :

- Les développements backend des espaces éleveur et vétérinaire.
